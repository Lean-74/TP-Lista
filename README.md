# Gestor de Contactos

Este proyecto es una aplicación web para administrar contactos personales.  
Permite cargar, editar y eliminar contactos de manera sencilla, con validaciones en tiempo real y almacenamiento local en el navegador.

La aplicación cuenta con varias páginas:
- **Inicio**: presentación del proyecto.
- **Lista**: sección principal donde se gestionan los contactos.
- **Acerca de**: información sobre el proyecto.
- **Ayuda**: guía básica de uso.

El diseño es responsive, pensado para funcionar en PC, tablet y celular.  
Los datos se guardan en el navegador mediante `localStorage`, por lo que no requieren servidor ni base de datos externa.
